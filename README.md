## The line

The phone's camera delivers its final words as the battery hits 1 percent —
one last photo, then the lens closes forever on 4,000 selfies it never
asked to see.

## How it works

`main.ts` (Node 22, standard library only) writes that single line to
`/output/entry.txt`. Nothing else is needed: no network, no secrets, no
dependencies.

```sh
node main.ts
cat /output/entry.txt
```
